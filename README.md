# Smart Bus Arrival Prediction System

## About the Project

The Smart Bus Arrival Prediction System is a Python-based application that helps students check bus arrival information.

## Features

- Select a bus
- View starting point
- View destination
- View start time
- View estimated arrival time
- Check bus availability

## Technologies Used

- Python
- Pandas
- Streamlit
- CSV Dataset

## Buses

- Veeramangala
- Uppinangadi
- Yedamangala

## Project Files

- app.py - Main Python application
- bus_data.csv - Bus information dataset
- requirements.txt - Required Python libraries
- README.md - Project documentation

## Future Improvements

- Real-time GPS tracking
- Machine Learning prediction
- Live bus location
- Mobile application
- Notifications

## Purpose

This project helps students easily check bus timing and arrival information.
